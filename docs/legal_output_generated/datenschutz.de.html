Für diese technische Bereitstellung nutzen wir GitHub Pages, einen Dienst von GitHub B.V. / GitHub, Inc. GitHub verarbeitet dabei bestimmte technische Daten in eigener datenschutzrechtlicher Verantwortlichkeit. Eine Verarbeitung kann in der EU, in den USA und in weiteren Ländern erfolgen, in denen GitHub, verbundene Unternehmen oder Unterauftragsverarbeiter tätig sind. Nach den aktuellen GitHub-Angaben werden für relevante Drittlandübermittlungen insbesondere Standardvertragsklauseln und das EU-U.S. Data Privacy Framework eingesetzt.

Lokale Speicherung im Browser

Diese Website verwendet browserseitigen localStorage für den Hinweis, dass es sich um eine archivierte Portfolio-Website handelt. Wenn Sie sich entscheiden, auf der Archiv-Website zu bleiben, speichern wir unter dem Schlüssel archiveNoticeDecisionV1 eine JSON-Information mit der Entscheidung stay und einem Ablaufzeitpunkt. Wenn Sie sich entscheiden, die Website zu verlassen, wird nichts gespeichert.

Diese Speicherung verhindert, dass der Archiv-Hinweis bei jedem Seitenaufruf erneut angezeigt wird. Sie erfolgt nur, um Ihre Entscheidung kurzfristig im Browser zu merken und die Archiv-Website entsprechend Ihrer Auswahl bereitzustellen. Rechtsgrundlage für die Speicherung von Informationen in Ihrer Endeinrichtung und den Zugriff darauf ist § 25 Abs. 2 Nr. 2 TDDDG. Eine Einwilligung ist hierfür nicht erforderlich, weil die Speicherung zur Umsetzung der von Ihnen ausdrücklich gewählten Anzeige der Archiv-Website erforderlich ist.

Der Eintrag wird durch das JavaScript dieser Website nach 24 Stunden gelöscht, wenn Sie die Website erneut besuchen, oder früher, wenn Sie den Speicher Ihres Browsers löschen.

Spam, fehlgeleitete und offensichtlich irrelevante Nachrichten löschen wir kurzfristig. Sonstige Kommunikation speichern wir grundsätzlich bis zum Abschluss des jeweiligen Vorgangs.
